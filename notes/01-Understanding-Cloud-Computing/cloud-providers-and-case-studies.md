## Cloud Providers and Case Studies

- cloud computing services are vital for modern companies
- IaaS and PaaS offer significant benefits
- cloud computing enable agility, efficiency, innovation
- reduce costs, focus on business

- **QUE: How to make a choice for a cloud provider??**
	- best cloud providers meet the company needs
	- leverage cloud specialists' knowledge
	- also have to consider current infrastructure and data center costs, evaluate costs for managing hardware and storage, and assess costs for app depreciation, migration or rebuild for cloud
		- consider hiring cloud specialists, benefits to company and customers, and potential cloud migration risks


**1. Amazon Web Services (AWS)**

- breadth of services offered by AWS include:
	- computing, storage, analytics, security and enterprise applications, & machine learning
- market share: 31%

AWS professional cloud services
1. AWS Simple Storage Service (S3) for file storage
2. AWS Elastic Compute Cloud (EC2) for computation
3. AWS Relational Database Service (RDS) for databases

AWS professional data services
1. Redshift - analytics / data warehousing
2. Kinesis - real time data movement & analytics
3. SageMarker - predictive analytics and machine learning


**2. Microsoft Azure**

- offers integration with Microsoft products
- benefits from customer loyalty, top-of-mind choice
- marker share: 24%

Azure cloud services
1. Azure Blob Storage
2. Azure Virtual Machines
3. Azure SQL Databases

- Microsoft Fabric which integrates various Microsoft solutions for enterprise use
	- covers data movement, data science, real-time analytics, business intelligence

Azure data services
- Data Lake Storage - store data before cleaning
- Stream Analytics - real-time analytics
- Machine Learning - train and deploy machine learning models


**3. Google Cloud**

- Google Cloud Anthos
	- run hybrid multi-cloud solutions:
		- manage and deploy across several cloud providers
- Market share: 11%

Google Cloud services
1. Google Cloud Storage
2. Google Cloud Compute Engine
3. Google Cloud SQL

Google Cloud data services
- Big Query (data warehouse)
- Dataflow (batch and stream data processing)
- AutoML (machine learning model training and development)
