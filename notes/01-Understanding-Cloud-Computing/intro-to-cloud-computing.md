## Introduction to Cloud Computing

- **QUE: what is cloud computing??**
    - cloud computing is the delivery of technology services—like computing power, storage, databases, and networking—over the internet with pay-as-you-go pricing. 
- companies can rent access to these services from cloud providers such as AWS, Microsoft Azure, or Google Cloud Platform.

- **QUE: how does cloud computing work??**
    - works by delivering computing resources over the internet instead of owning and managing physical hardware. 
	- _instead of hosting on physical servers owned by the company locally, the company host their services such as website on cloud servers and can easily be scaled up or down instantly based on demand_.

- cloud computing is flexible, scalable, and quick to set up; however security and cost can be an issue. 
- on-premise servers can offer control and security, however, they can be challenging to scale and expensive to maintain.
- Note: cloud computing is not just for hosting websites—it also powers data storage, backups, AI models, streaming services, and much more. 


**The Power of the Cloud**

- three key services offered by cloud providers:
	- compute, storage, and databases
		- compute is the "brain" that processes workloads
		- storage saves files and data
		- databases store data for easy retrieval, management and analysis
- cloud computing offers a lot of advantages in terms of cost, speed, performance, scalability, reliability, and security
- virtualisation - is the process of splitting one physical server into multiple virtual servers, each acting like its own independent machine. offers better resource efficiency, lower costs, and easier management
- scalability - adjusting resources based on demand
	- vertical scaling upgrades an existing machine's power - more RAM, CPU etc
	- horizontal scaling adds more machines to share the workload which is perfect for handling website traffic spikes. 
- pay-as-you-go pricing - means only pay for what's needed
- peed - on demand resources enables quick launch of services and applications
- realibility - cloud providers replicate data across multiple data centers so that if one goes down, the data is still safe. 
	- means less downtime, fewer outages, and more peace of mind. 
- security - very important


**Cloud Service Models**

- there are different cloud service models and three most common ones are:
	1. Infrastructure as a Service (IaaS) - scalabale, cloud-based infrastructure used by system admins for example Amazon EC2 and Google Cloud Compute Engine
	2. Platform as a Service (PaaS) - full development environments used by developers e.g., Google App Engine, AWS Elastic Beanstalk
	3. Software as a Service (SaaS) - software available online, no installation needed. used by everyone (end users) e.g., Google Workspace, Dropbox, and Office 365
	4. Function as a Service (FaaS) - serverless computing which focuses on a function (part of the software) e.g., identity authentication, payment transactions. pay for what you use!!
	5. Anything as a Service (XaaS) - covers everything from databases to disaster recovery e.g., Google Cloud, Azure etc
- in IaaS we get networking, storage, and servers
- in PaaS get networking, storage, servers, virtualisation
- in SaaS everything is managed for the client. get networking, storage, servers, virtualisation, O/S, middleware, runtime, data, and applications.
