## Introduction to Cloud Migration

- migrating to the cloud involves moving the organisation's data, applications, and workloads from on-premises infrastructure to the cloud. 
- AWS Cloud Adoption Framework (AWS CAF) is a framework which provides a structured approach to cloud migration, helping organisations design and implement a migration strategy that aligns with their business goals.
- benefits of the CAF:
	1. reducing risk: e.g., backing up data and defining transfer protocols
	2. improving ESG performance: implementing sustainable cloud solutions. optimise usage, reduce waste, lower energy consumption. for example: use of auto-scaling to ensure usage of required resources
	3. increasing revenue and operational efficiency: automate migration operations leading to greater operational efficiency

- common migration strategies:
	1. AWS Database Migration Service (DMS)
		- replicating existing database with minimal disruption
		- fully operational during transition
	2. AWS Snowball
		- physical data transport for large-scale migrations
