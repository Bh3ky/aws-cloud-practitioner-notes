## Understanding Concepts of Cloud Economics

- **QUE: what is cloud economics??**
	- refers to the financial considerations of moving to the cloud
	- opportunities to significantly reduce IT expenses compared to traditional IT setups:
		- flexible pricing models, efficient resource usage, and elimination of fixed costs. 
- **QUE: difference between fixed and variable costs??**
	- fixed : include upfront capital expenditures for hardware, data centers, and maintanance etc. 
		- paying for full capacity whether it's used or not. also incur ongoing costs
	- variable: pay for what you use

**Bring Your Own Licenses (BYOL)**
- avoid sunk costs. port existing licenses to AWS infrastructure. cost-effective by leveraging current investment
- alternative: AWS includes licenses bundled into service which simplifies management and potentially reduces overall costs

- right-sizing - involves adjusting the resources allocated to the workloads to match actual demand. 
	- flexibility: significant cost savings and dynamic environment
- automation - plays a key role in cost efficiency. 
	- AWS CloudFormation allows us to automate the setup and also helps manage the cloud resources
	- reduces time, minimises human error and ensures consistent configuration
- AWS managed services: Amazon RDS for databases, AWS Lambda for serverless computing, and Amazon S3 for storage handle of the underlying infrastructure management.
